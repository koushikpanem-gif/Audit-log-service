Exact v1 crypto protocol
All text is UTF-8, hashes lowercase 64-hex, || is byte concatenation and 0x00 is one zero byte. JCS is RFC 8785 canonical JSON: UTF-16 property ordering, ECMAScript shortest number formatting, no whitespace, valid Unicode, negative zero -> 0. Reject duplicate JSON keys, NaN/infinity, lone surrogates and integer tokens outside +/-9007199254740991 before lossy conversion. Monetary precision uses strings. Validate depth/size before recursive work.
genesis = SHA256(UTF8("audit-log/genesis/v1") || 0x00 || UTF8(ledgerId)).
leaf = SHA256(UTF8("audit-log/leaf/v1") || 0x00 || randomSalt[32] || 0x00 || UTF8(pointer) || 0x00 || JCS(value)).
contentHash = SHA256(UTF8("audit-log/content/v1") || 0x00 || JCS(content)).
chainHash = SHA256(UTF8("audit-log/chain/v1") || 0x00 || hexDecode(prevHash)[32] || hexDecode(contentHash)[32]).
content has EXACT keys {v:1,seq,eventId,eventType,actorId,resourceType,resourceId,occurredAt,recordedAt,source,payload:commitmentTree}; occurredAt is explicitly null when absent. API timestamp maps to recordedAt in this hashed object. Hash version 1 is immutable; new formats need a version and compatibility plan.
Payload is a JSON object; preserve object/array shape, replace each scalar including null with its salted commitment string; empty objects/arrays remain empty. Store plaintext scalar and salt separately under RFC6901 pointer (escape ~ as ~0 and / as ~1; indices canonical decimal). Fresh cryptographic salt per leaf, never deterministic in real writes. Reveal absent values as "[REDACTED]" plus sorted redactedPaths.
Ed25519 signs JCS(message), signature standard Base64. Private key PKCS#8 PEM; public key field Base64 of raw 32 bytes. keyId is first 16 hex chars of SHA256(raw public key). Java must correctly convert JDK public key encoding, not publish X.509 DER as raw bytes. Checkpoint message EXACT {type:"audit-checkpoint/v1",ledgerId,seq,chainHash,createdAt}; signature and keyId are outside the signed message. Sign every configured N appends (default100), on demand, export/archive/report. No empty-ledger checkpoint: 409. Key created exclusively in dev with restrictive permissions; prod requires existing valid key and API keys file. Never overwrite a key silently.

Storage and transactions
SQLite WAL, synchronous=FULL, foreign_keys=ON, secure_delete=ON, busy_timeout=30000 on every connection. BEGIN IMMEDIATE before reading head for every mutation, rollback on error; snapshot transaction for multi-read operations. One ledger per DB; ledger_meta binds ledgerId/schema version and rejects mismatch.
audit_events: seq INTEGER PK, event_id TEXT UNIQUE NOT NULL, event_type/actor_id/resource_type/resource_id/occurred_at/source/payload_commitments nullable only where appropriate for archive, recorded_at TEXT NOT NULL, hash_version INTEGER NOT NULL, content_hash/prev_hash/chain_hash TEXT NOT NULL, archived INTEGER 0/1 default0, archived_at TEXT.
payload_leaves: (seq FK,pointer TEXT,salt TEXT hex,value TEXT JSON), PK(seq,pointer).
checkpoints: id INTEGER PK AUTOINCREMENT,seq,chain_hash,created_at,key_id,signature (required).
Indexes (actor_id,seq),(resource_type,resource_id,seq),(event_type,seq),(recorded_at,seq). Version migrations explicitly. Add durable cleanup jobs and archive job metadata when implementing their steps.
Triggers: block audit_events DELETE, all updates except archive 0->1 preserving seq/event_id/recorded_at/hash_version/all hashes; block payload leaf UPDATE; block checkpoint UPDATE/DELETE. Triggers are accidental-write guardrails, not protection against a DB administrator. Tests must create matching rows before expecting row-level triggers to fire.
seq starts1, prevHash=genesis for first then stored previous chainHash. Server recordedAt is UTC YYYY-MM-DDTHH:mm:ss.ffffffZ and max(now,previous timestamp), nondecreasing (ties allowed). Sequence determines order. Optional occurredAt normalized UTC, maximum300 seconds future skew; caller timestamp rejected with422.

Return201 with cleanupStatus COMPLETE/PENDING, never imply committed deletion rolled back. No physical-erasure guarantee for storage devices/backups/earlier exports/archive copies.
